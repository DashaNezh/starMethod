### Вопросы по общим концепциям pandas

**Q1: Что такое DataFrame в pandas?**
- **Ответ:** DataFrame — это двумерная структура данных (таблица), похожая на таблицу Excel. Состоит из строк (index) и столбцов (columns). Каждый столбец может содержать данные разного типа.

**Q2: В чем разница между `loc[]` и `iloc[]`?**
- **Ответ:** `loc[]` использует **метки** (названия строк/столбцов), а `iloc[]` использует **индексы** (позиции 0, 1, 2...). Например: `df.loc[0, 'Name']` — по метке, `df.iloc[0, 1]` — по индексу.

**Q3: Что делает `axis=1` в операциях pandas?**
- **Ответ:** `axis=1` означает работу **по столбцам** (горизонтально), `axis=0` — по строкам (вертикально). В `drop()`: `axis=1` — удалить столбцы, в `apply()`: `axis=1` — применить функцию к каждой строке.

**Q4: Зачем нужен `reset_index()` после `groupby()`?**
- **Ответ:** После `groupby()` столбцы группировки становятся индексом (не обычными столбцами). `reset_index()` преобразует их обратно в обычные столбцы, чтобы можно было работать как с обычным DataFrame.

**Q5: В чем разница между `apply()` и `map()`?**
- **Ответ:** `apply()` — применяет функцию к элементам Series или строкам/столбцам DataFrame. `map()` — заменяет значения в Series по словарю или функции. `apply()` более универсален, `map()` быстрее для простых замен.

### Вопросы по работе с датами

**Q6: Что делает `dayfirst=True` в `pd.to_datetime()`?**
- **Ответ:** Указывает, что даты в формате **день/месяц/год** (например, "01/12/2017" = 1 декабря), а не месяц/день/год (12 января). Без этого параметра pandas может неправильно интерпретировать даты.

**Q7: Что делает `errors='coerce'` в `pd.to_datetime()`?**
- **Ответ:** При ошибке парсинга даты вместо остановки программы создается значение `NaN` (Not a Number). Это позволяет обработать невалидные даты без прерывания выполнения кода.

**Q8: Какие методы доступны через `.dt` для работы с датами?**
- **Ответ:** `.dt.year`, `.dt.month`, `.dt.day`, `.dt.hour`, `.dt.weekday`, `.dt.day_name()`, `.dt.date` и другие. Позволяют извлекать различные компоненты даты и времени.

**Q9: Как получить только дату без времени из datetime?**
- **Ответ:** Используй `.dt.date` — вернет только дату (объект date). Например: `df['Date'].dt.date` вернет серию только с датами.

### Вопросы по группировке и агрегации

**Q10: Что делает `groupby()`?**
- **Ответ:** Разделяет данные на группы по значениям указанного столбца(ов), затем можно применить агрегирующую функцию (sum, mean, count и т.д.) к каждой группе. Это аналог PIVOT в SQL.

**Q11: В чем разница между `groupby().sum()` и `groupby().agg('sum')`?**
- **Ответ:** Практически никакой — это два способа написать одно и то же. `agg()` более гибкий — позволяет указать несколько функций сразу: `agg(['sum', 'mean', 'count'])`.

**Q12: Когда использовать `pivot_table()` вместо `groupby()`?**
- **Ответ:** `groupby()` создает длинную таблицу (все группы в одной колонке), а `pivot_table()` создает широкую таблицу (группы как столбцы). Используй `pivot_table()` когда нужна сводная таблица (как в Excel).

**Q13: Что означает `aggfunc` в `pivot_table()`?**
- **Ответ:** Функция агрегации — как считать значения в ячейках таблицы. Может быть: 'sum', 'mean', 'count', 'max', 'min' и другие. Определяет, что будет в ячейках пересечения строк и столбцов.

**Q14: Что делает `fill_value=0` в `pivot_table()`?**
- **Ответ:** Заполняет пустые ячейки нулями вместо NaN. Полезно когда в некоторых комбинациях строк/столбцов нет данных и нужно показать 0 вместо пропуска.

### Вопросы по фильтрации и условиям

**Q15: Как правильно написать несколько условий в `loc[]`?**
- **Ответ:** Каждое условие в скобках, между ними `&` (И) или `|` (ИЛИ). Например: `df.loc[(df['A'] > 5) & (df['B'] < 10)]`. Важно: каждое условие в скобках!

**Q16: Почему нельзя использовать `and` вместо `&` в фильтрации?**
- **Ответ:** `and` работает с булевыми значениями, а `&` — побитовая операция, которая работает с массивами pandas. `&` применяется поэлементно к каждой строке, что и нужно для фильтрации.

**Q17: Как выбрать конкретные столбцы после фильтрации?**
- **Ответ:** Укажи список столбцов после запятой в `loc[]`: `df.loc[условие, ['столбец1', 'столбец2']]`. Это сделает результат более читаемым.

### Вопросы по созданию новых столбцов

**Q18: Когда использовать `apply()` с `lambda`, а когда с обычной функцией?**
- **Ответ:** `lambda` — для простых однострочных операций: `df['col'].apply(lambda x: 1 if x > 5 else 0)`. Обычная функция — для сложной логики с несколькими условиями и строками кода.

**Q19: Зачем нужен `axis=1` в `apply()` для создания столбца?**
- **Ответ:** `axis=1` означает применение функции к каждой **строке** (а не к каждому элементу). Нужен когда функция обращается к нескольким столбцам одновременно: `df.apply(lambda row: row['A'] + row['B'], axis=1)`.

**Q20: Что такое `.transform()` и чем отличается от `groupby().mean()`?**
- **Ответ:** `transform()` возвращает результат того же размера, что и исходные данные (каждая строка получает значение своей группы). `groupby().mean()` возвращает сводку по группам (меньше строк). Используй `transform()` когда нужно добавить агрегированное значение в каждую строку.

### Вопросы по поиску максимума/минимума

**Q21: В чем разница между `.max()` и `.idxmax()`?**
- **Ответ:** `.max()` возвращает **максимальное значение**, а `.idxmax()` возвращает **индекс строки** с максимальным значением. `idxmax()` нужен чтобы потом получить всю строку через `loc[]`.

**Q22: Как найти строку с максимальным значением?**
- **Ответ:** `df.loc[df['столбец'].idxmax()]` — найдет индекс строки с максимумом и вернет всю строку. Можно указать конкретные столбцы: `df.loc[df['столбец'].idxmax(), ['col1', 'col2']]`.

### Вопросы по конкретным заданиям из лабы

**Q23: Почему в задании 5 мы группируем по `df['Date'].dt.date`, а не просто по `Date`?**
- **Ответ:** `Date` включает время (часы), поэтому каждая запись уникальна. `dt.date` убирает время и оставляет только дату, позволяя группировать все записи за один день вместе.

**Q24: Почему в задании 8 используется `axis=1` в `apply()`?**
- **Ответ:** Функция `good_weather()` обращается к нескольким столбцам одновременно (`row['Temperature category']`, `row['Humidity']` и т.д.). `axis=1` применяет функцию к каждой строке, давая доступ ко всем столбцам строки.

**Q25: Что означает `errors='coerce'` в преобразовании даты?**
- **Ответ:** Если дата не может быть распознана, вместо ошибки создается `NaN`. Это позволяет обработать файл даже если некоторые даты невалидны, не прерывая выполнение программы.

**Q26: Зачем мы использовали `.copy()` в задании 4?**
- **Ответ:** `.copy()` создает копию данных, а не ссылку. Это предотвращает предупреждения pandas о работе с "view" (представлением) данных и гарантирует, что изменения не затронут исходный DataFrame.

**Q27: Почему в задании 7 мы создали функцию `temp_category()`, а не использовали lambda?**
- **Ответ:** Lambda хорош для простых условий (1-2 условия), но здесь 4 разных диапазона температур. Функция более читаема и понятна для сложной логики с несколькими `elif`.

**Q28: Что делает `.reset_index(name='Hours_open')` в задании 5?**
- **Ответ:** После `groupby()` и `sum()` результат имеет имя столбца по умолчанию. `name='Hours_open'` переименовывает столбец с суммой в 'Hours_open' для наглядности.

**Q29: Почему в задании 9 мы использовали и `groupby()`, и `pivot_table()`?**
- **Ответ:** Чтобы показать два способа группировки. `groupby()` дает длинную таблицу (удобно для дальнейшего анализа), `pivot_table()` дает широкую таблицу (удобно для визуализации и сравнения).

### Вопросы по статистике и анализу

**Q30: Что такое корреляция и как ее интерпретировать?**
- **Ответ:** Корреляция показывает связь между двумя переменными. От -1 до 1: близко к 1 — сильная прямая связь, близко к -1 — сильная обратная связь, близко к 0 — связи нет. `.corr()` вычисляет коэффициент корреляции Пирсона.

**Q31: Что означает `.mean() * 100` для бинарной переменной?**
- **Ответ:** Для переменной с 0 и 1, среднее дает долю единиц (вероятность). Умножение на 100 преобразует в проценты. Например, если среднее = 0.0927, то 9.27% значений равны 1.

**Q32: Что такое квантили и зачем они нужны?**
- **Ответ:** Квантили разделяют данные на части. `quantile(0.33)` — значение, ниже которого 33% данных. Используются для разделения на категории (Low/Medium/High) или для поиска выбросов.

### Вопросы по эффективности и лучшим практикам

**Q33: Когда использовать `inplace=True`?**
- **Ответ:** `inplace=True` изменяет исходный DataFrame вместо создания нового. Полезно когда исходные данные больше не нужны. Но лучше избегать — безопаснее работать с копиями: `df = df.drop(...)`.

**Q34: Что делать если получил предупреждение "SettingWithCopyWarning"?**
- **Ответ:** Это значит, что работаешь с "view" (представлением) данных, а не с копией. Добавь `.copy()` после фильтрации: `df_filtered = df.loc[условие].copy()`.

**Q35: Как проверить размер DataFrame?**
- **Ответ:** `len(df)` — количество строк, `df.shape` — кортеж (строки, столбцы), `df.info()` — подробная информация о типах данных и памяти.

### Вопросы по отладке и ошибкам

**Q36: Что делать если "KeyError: 'столбец'" возникает?**
- **Ответ:** Проверь точное название столбца через `df.columns`. Возможны пробелы, разный регистр букв. Используй `df.columns.tolist()` чтобы увидеть все названия.

**Q37: Что означает ошибка "ValueError: The truth value of a Series is ambiguous"?**
- **Ответ:** Ты пытаешься использовать `and`/`or` с Series pandas. Используй `&` и `|` для побитовых операций. Убедись что каждое условие в скобках.

**Q38: Как проверить есть ли пропущенные значения (NaN)?**
- **Ответ:** `df.isna().sum()` — покажет количество NaN в каждом столбце, `df.isna().any()` — есть ли хотя бы один NaN, `df.dropna()` — удалить строки с NaN.

### Вопросы по применению знаний

**Q39: Как бы ты нашел среднюю температуру для каждого месяца?**
- **Ответ:** 
```python
avg_temp_by_month = df.groupby('Month')['Temperature'].mean().reset_index()
display(avg_temp_by_month)
```
Или если нужно еще и по годам: `df.groupby(['Year', 'Month'])['Temperature'].mean()`

**Q40: Как бы ты создал столбец "Будний день" (1 если будний, 0 если выходной)?**
- **Ответ:**
```python
df['Weekday_num'] = df['Weekday'].apply(lambda x: 0 if x in ['Saturday', 'Sunday'] else 1)
```
Или через функцию:
```python
def is_weekday(day):
    return 0 if day in ['Saturday', 'Sunday'] else 1
df['Weekday_num'] = df['Weekday'].apply(is_weekday)
```

**Q41: Как бы ты сравнил аренды в разные сезоны?**
- **Ответ:**
```python
season_comparison = df.groupby('Seasons')['Total_count'].agg(['sum', 'mean', 'count']).reset_index()
display(season_comparison.sort_values('sum', ascending=False))
```

```python
hourly_by_weekday = df.groupby(['Weekday', 'Hour'])['Total_count'].sum().reset_index()
max_hour_per_day = hourly_by_weekday.loc[hourly_by_weekday.groupby('Weekday')['Total_count'].idxmax()]
display(max_hour_per_day)
```
